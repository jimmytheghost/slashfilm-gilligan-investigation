# Charts

The report's chart PNGs are generated as temporary build assets by `scripts/build_gilligan_report.py`; the finished chart packet is embedded in the PDF under `output/pdf/`.

The report includes:

- Gilligan-related stories over time
- Selected franchise coverage counts
- Monthly Gilligan cadence
- Gilligan's Island versus its principal cast
- Current-TV comparisons, including *Stranger Things*
